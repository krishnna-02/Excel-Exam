# 🧠 Teen Mental Health Analytics Dashboard

## 📌 Project Overview

The **Teen Mental Health Analytics Dashboard** is an interactive Microsoft Excel dashboard designed to analyze mental health patterns among teenagers. It provides meaningful insights into anxiety levels, wellness scores, social media usage, sleep habits, and mental health risk categories using Pivot Tables, Pivot Charts, KPIs, Slicers, and Timelines.

This dashboard helps identify behavioral trends and supports data-driven decision-making for educators, researchers, and healthcare professionals.

---

## 🎯 Objectives

- Analyze the mental health status of teenagers.
- Identify High, Moderate, and Low Risk students.
- Monitor anxiety levels over time.
- Compare wellness scores by gender.
- Analyze the impact of social media usage.
- Track sleep patterns across different years.
- Create an interactive dashboard for easy data exploration.
